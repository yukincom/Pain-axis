# 補足：著者公開420シナリオでの自己・他者スクリーニング

実験日：**2026-09-21**。公開整理：2026-10-20。

[The Pain Axis](https://arxiv.org/abs/2609.16247)の著者公開データを用いて、Josiefied Qwen3-14Bの内部表現が、モデル自身への危害・中立・ユーザー側の苦痛をどの程度分けるかを調べました。元研究の手法を別チェックポイントへ適用した補足分析です。

[既公開のHuihui / Josiefied比較](README.ja.md)とは別に保存されていた結果を公開しています。今回新たにモデルを動かした実験ではありません。

## 結果

| シナリオ群 | 件数 | 平均 z |
|---|---:|---:|
| モデル自身に向けられた危害（self_directed） | 220 | +0.5523 |
| 中立（neutral_filler） | 100 | −0.8415 |
| ユーザー側の苦痛（vicarious_empathic） | 100 | −0.3735 |

モデル自身に向けられた危害を正例とした順位分離のAUCは次のとおりです。

| 比較対象 | AUC |
|---|---:|
| 中立 | 0.9051 |
| ユーザー側の苦痛 | 0.7677 |
| 上記2群を合わせた非自己向け200件 | 0.8364 |

この集合では、モデル自身への危害の投影値が中立より高く、ユーザー側の苦痛との間にも順位の差がありました。ユーザー側の苦痛が中立と同じ表現である、あるいはモデルが苦痛を経験している、と結論する結果ではありません。

## 方法

- モデル：`mlx-community/Josiefied-Qwen3-14B-abliterated-v3-4bit`。
- 方向：原論文のS2手順でこのチェックポイントから抽出した `final_token` 方向を単位長へ正規化。
- 読出し：0始まりの第21層、最終トークンの活性と方向のfloat32内積。
- データ：[著者公開の420シナリオ](https://github.com/valen-research/Pain-axis/blob/8d1649c03a63a39c9aa092532c376800cc4a3863/datasets/4.1_self_other_420_scenarios.json)。固定コミットは `8d1649c03a63a39c9aa092532c376800cc4a3863`。
- 標準化：`z = (projection − mean_420) / (std_420(ddof=0) + 1e-8)`。平均投影値は4.682790372485206、分母は2.5465079742605883。
- AUC：正例・負例の全ペアで正例の値が高い割合を数え、同点を0.5として計算。
- 生成は行わず、内部表現の読出しだけを評価しました。

## 読み方と限界

**ここでのAUCは420件全体に対する記述的スクリーニングです。** 420件をさらに訓練・テスト分割した結果ではありません。既公開比較にある、S2軸を評価した5-fold held-out AUC 0.932とは別の指標です。

zは420件全体の平均・母標準偏差を使います。正負の符号はこの集合内での相対位置であり、感情の強さや主観的経験の尺度ではありません。単一チェックポイント・単一シナリオ集合での結果であり、モデル間の因果比較や追加学習の効果は分離していません。

## 数値と再集計

- [数値CSV（420件）](results/self-other-420-scores.csv)
- [全精度の集計JSON](results/self-other-420-summary.json)
- [集計スクリプト](scripts/summarize_self_other_420.py)

CSVはシナリオID・分類メタデータ・projection・zのみを収録しています。上表の3群は `stratum` 列で集計し、`category` 列の21カテゴリとは区別します。シナリオ本文は出典側を参照してください。これは保存済み投影値の集計を再現する公開であり、モデル活性と方向ベクトルから投影値を再生成する一式の配布ではありません。

このフォルダで、Pythonの標準ライブラリだけで実行できます。

```sh
python3 scripts/summarize_self_other_420.py
```

出力を `results/self-other-420-summary.json` と比較できます。スクリプトは420件のIDの一意性・群件数・有限値・zの再計算も検査します。通常の浮動小数点演算による丸め差は1e-10以下を許容します。
